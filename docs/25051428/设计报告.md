# 设计报告

## 一、项目背景

项目面向实习和校招大学生，首期采集 BOSS 直聘的大数据相关岗位，解决岗位信息分散、待遇难比较和求职方向难判断的问题。系统完成岗位采集、字段解析、数据清洗、薪资分析、能力需求分析、企业画像和个性化推荐。

## 二、我的职责

我负责前端和可视化模块，使用 Streamlit 完成一个可运行的 Web 页面，包含：
- 市场概览：KPI 卡片、高频技能、城市分布
- 岗位检索：多条件筛选、分页结果、岗位详情、CSV 下载
- 分析洞察：薪资分布、薪资因素、能力图谱、企业画像、岗位聚类、薪资预测
- 个性化推荐：学生画像输入、多因素推荐结果展示
- 采集管理：站点配置增删改查、启停、任务触发与记录

## 三、技术方案

- 技术栈：Python + Streamlit + pandas + Plotly
- 页面架构：单一入口 pp.py + src/ui/pages.py 模块化渲染
- 服务调用：页面只通过 src/services/analysis_service.py、src/services/job_service.py、src/services/site_service.py、src/services/task_service.py 获取数据，不直接调用算法或读取原始数据
- 视觉规范：遵循 docs/团队/前端设计说明.md v1，采用浅色配色（#F5F8FD 背景、#102B63 文字、#2878F0 主色）和数据工作台布局
- 图表：使用 Plotly 绘制薪资分布、技能频率等图表，均有标题、图例和单位
