## 遇到的问题与解决

1. **共享接口不一致**：src/data/schema.py 的 StudentProfile 只有 target_role / skills / preferred_city / experience / 薪资区间，缺《接口约定.md》规定的 education、major、school、work_years、work_experience。**解决**：组长确认"出现问题在自己分支改，改完提 PR 他审核"，已在本分支补全字段并对齐接口约定（保留 experience 兼容字段），原 JOB_COLUMNS 等共享契约未动，smoke.py 全过。
2. **本地环境缺依赖**：python 3.13 全局环境未装 pandas/sklearn，按 README 创建 .venv 虚拟环境解决。
3. **pandas 元组索引坑**：`pd.DataFrame(rows)[RECOMMENDATION_COLUMNS]` 报 KeyError——pandas 把元组当作 MultiIndex 键。**解决**：改为 `[list(RECOMMENDATION_COLUMNS)]` 显式转列表。
4. **测试断言想当然**：以为"期望薪资 20-30K"时第一行 reason 必含"低于期望"，实际第一行是薪资区间命中的岗位（"符合期望"），因为薪资权重高于文本相似度差距。**解决**：先打印实际输出再修正断言为 `any(...)` 语义。
5. **二轮 review 修复未随 PR #4 进入 main**：修复提交 c6b5603 因推送网络故障未及时上远端，组长合并 PR 时分支上还没有该提交；组长在 merge 时自己实现了等价修复（_multifactor_jobs 统一补齐可选列），经查 origin/main 代码与回归测试均已覆盖，无需重复提交，仅课程目录迁移需要单独 PR。
6. **git push 连接反复失败**：多次重试均超时。**解决**：用 netstat 扫出本机 7897 端口代理（Clash 类工具），显式指定 http.proxy 后成功。
7. **git clean / git mv 目录残留**：切换分支后 OneDrive 目录中旧分支文件未被清理，导致 git mv 嵌套（daily/25051415/dingweizhe）。**解决**：git reset 取消暂存、git clean 删除残留文件、逐级 rmdir 清空目录壳后重新 git mv，确认 rename 0 行变化。
8. **merge 冲突**：docs/接口约定.md 的 StudentProfile experience 行，本分支详细版与远端（徐挚凌 5a26bcd）简版冲突。**解决**：保留语义更完整的版本（说明 experience 与 work_years/work_experience 的分工），与合并后 schema.py docstring 一致；main 最终版以组长批准版本为准。
