```bash

```
数据来源二选一：
- 样例数据（本模块独立测试数据）：`from tests.sample_data import build_sample_frame`

**通用入参约定**：所有函数都接收**标准岗位表**（字段见《接口约定》），不读文件、不依赖页面。

## 1. 薪资因素分析 `analyze_salary_factors`
```python
from src.algorithms.salary import analyze_salary_factors
from tests.sample_data import build_sample_frame

df = analyze_salary_factors(build_sample_frame())
# -> DataFrame，列为：
#   factor | impact_direction | importance | description
```
真实输出样例：
```
factor                    impact_direction  importance  description
city-上海                 higher           0.2462      该组岗位平均月薪 33167 元（样本 6），整体均值 23519 元；...
company_nature-国企       higher           0.1830      该组岗位平均月薪 29500 元（样本 6），整体均值 23519 元；...
company_size-100-499人    lower            0.1749      该组岗位平均月薪 16600 元（样本 5），整体均值 23519 元；...
```
**展示字段**：`factor`（因子）、`impact_direction`（higher/lower/neutral）、`importance`（0~1）、`description`（说明文字）。

## 2. 能力需求图谱 `build_skill_graph`
```python
from src.algorithms.skill_graph import build_skill_graph

g = build_skill_graph(build_sample_frame())
# -> dict，键为：
#   nodes = [{id, label, count}]       技能节点及频次
#   edges = [{source, target, weight}] 技能共现关系
#   skill_frequency = [(skill, count)] 技能频率（降序）
```
真实输出样例：
- nodes=42、edges=99；`skill_frequency` Top5：`[('Python',19),('SQL',19),('Excel',9),('Spark',5),('机器学习',4)]`
- `edges` Top3：`[{'Python','SQL',11}, {'Excel','SQL',8}, {'Excel','Python',4}]`

**展示字段**：节点（`id/label/count`）、连线（`source/target/weight`）、词频（`skill_frequency`）。

## 4. KMeans 聚类 `cluster_jobs`
```python
from src.algorithms.clustering import cluster_jobs

jobs_with_label, group_desc = cluster_jobs(build_sample_frame(), n_clusters=3)
# jobs_with_label: DataFrame = 原岗位表 + cluster_id
# group_desc: dict = {cluster_id: {count, salary_avg, salary_range, top_skills, dominant_education, dominant_city}}
```
真实输出样例：
- 群组分布：cluster 0→9、1→4、2→17
- 群组0 说明：`{count:9, salary_avg:28375, salary_range:[17000,42000], top_skills:[Python,SQL,PyTorch,Spark,机器学习], dominant_education:本科, dominant_city:广州}`
- 单条样例：j05 机器学习工程师（上海，38000）→ cluster_id=0

**展示字段**：每条岗位的 `cluster_id` + 群组说明（可作下拉/图例说明文字）。

## 5. 随机森林薪资预测 `predict_salary`
```python
from src.algorithms.salary import predict_salary

pred, metrics = predict_salary(build_sample_frame())
# pred: DataFrame = 原岗位表 + predicted_salary
# metrics: dict = {'mae': ..., 'r2': ...}
```
真实输出样例：
- `metrics = {'mae': 3416.67, 'r2': 0.7635}`
- 样例：j01 实际 15000→预测 16950；j03 实际 25000→预测 25350；j05 实际 38000→预测 37900（缺失薪资 j02→预测 14350）

**展示字段**：`predicted_salary`、`mae`、`r2`。

## 6. 异常状态约定（服务层应透传提示）
| 场景 | 抛错信息 |
|---|---|
| 空岗位表 | `岗位数据为空，无法进行分析` |
| 缺必填字段 | `岗位表缺少必填字段: ...` |
| 聚类样本不足 | `岗位样本不足（N 条，至少需要 M 条）...` |
| n_clusters<2 | `n_clusters 至少为 2` |
| 薪资有效样本<6 | `薪资有效样本过少（N < 6）...` |

服务层建议捕获 `ValueError` 并转换为统一返回码，前端展示明确提示而非 500。
