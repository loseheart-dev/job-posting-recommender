## 遇到的问题与解决

1. **共享接口不一致**：src/data/schema.py 的 StudentProfile 只有 target_role / skills / preferred_city / experience / 薪资区间，缺《接口约定.md》规定的 education、major、school、work_years、work_experience。**解决**：组长（卢世豪）确认"出现问题在自己分支改，改完提 PR 他审核"，已在本分支补全字段并对齐接口约定（保留 experience 兼容字段），原 JOB_COLUMNS 等共享契约未动，smoke.py 全过。
2. **本地环境缺依赖**：python 3.13 全局环境未装 pandas/sklearn，按 README 创建 .venv 虚拟环境解决。
3. **pandas 元组索引坑**：`pd.DataFrame(rows)[RECOMMENDATION_COLUMNS]` 报 KeyError——pandas 把元组当作 MultiIndex 键。**解决**：改为 `[list(RECOMMENDATION_COLUMNS)]` 显式转列表。
4. **测试断言想当然**：以为"期望薪资 20-30K"时第一行 reason 必含"低于期望"，实际第一行是薪资区间命中的岗位（"符合期望"），因为薪资权重（0.1）高于文本相似度差距。**解决**：先打印实际输出再修正断言为 `any(...)` 语义。
5. **课程提交目标不确定（待确认）**：课程说明要求提交到 gitee 仓库，本组实际是 GitHub 仓库，需确认课程扫描系统能覆盖。
