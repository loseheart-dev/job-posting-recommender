# 项目报告

## 一、项目概况

项目名称为“面向大学生求职的岗位数据分析与个性化推荐系统”。项目面向实习和校招大学生，首期以 BOSS 直聘的大数据相关岗位为数据入口，形成“采集—清洗—分析—推荐—展示”的处理链路。

## 二、当前实现

已进入主分支的内容包括：

- `src/data/boss_adapter.py`：导入 BOSS 上游 JSON/CSV，映射岗位和企业字段；
- `src/data/traversal.py`、`scripts/run_boss_tasks.py`：按任务执行 BFS/DFS，并记录访问和结果；
- `src/data/cleaner.py`：去重、空值标记、薪资解析、地区和字段标准化；
- `src/services/site_service.py`、`task_service.py`：网站配置、启停、频率和采集任务记录；
- `src/algorithms/recommender.py`：TF-IDF 基线、多因素推荐、匹配概率和推荐理由；
- `tests/`：采集清洗、推荐、服务和异常输入测试。

原始数据保存在 `data/raw/`，清洗结果按约定输出到 `data/processed/jobs.csv`。真实账号状态、Cookie 和个人信息不进入仓库，测试使用公开化样例数据。

## 三、技术方案

项目使用 Python、pandas、PySpark/Spark、scikit-learn 和 Streamlit。采集层参考 `boss-zhipin-scraper`，数据层统一岗位字段，服务层提供配置、任务和筛选接口，算法层负责推荐和后续主题分析，展示层由 Streamlit 调用服务结果。

## 四、验证情况

当前主分支已通过 38 项 `unittest`、服务契约 smoke test、Python 编译检查和 Git 空白检查。已覆盖正常岗位数据、空文件、缺字段、坏格式、缺失技能、空画像和最小必要岗位字段等案例。
