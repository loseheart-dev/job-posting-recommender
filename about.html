PROJECT OVERVIEW

把招聘信息，变成可行动的求职信号。

Career Signal 面向实习、校招和转型阶段的求职者，整理在线招聘岗位中的薪资、城市、学历、经验、技能和企业信息，帮助用户看懂市场、比较机会，并获得有依据的岗位推荐。

采集→清洗→分析→推荐→展示
01 / DATA

岗位数据采集

从 BOSS 直聘采集岗位列表，保留来源和采集时间，统一处理职位、薪资、地区、企业、学历、经验、技能与福利等信息。

02 / INSIGHT

市场分析

通过薪资因素分析、岗位能力需求图谱、企业画像、岗位聚类和薪资预测，呈现岗位市场的结构与差异。

03 / MATCH

个性化推荐

结合目标岗位、学历、专业、城市、经验、技能和期望薪资，输出岗位匹配度、企业信息、匹配技能和待提升技能。

项目如何工作

系统先将招聘平台的非结构化信息转换为统一岗位数据，再由服务层提供检索和统计接口，分析模块负责挖掘市场规律，推荐模块最后根据求职者画像生成结果。页面只负责交互和展示，各模块通过固定字段协作。

数据入口BOSS 直聘岗位数据；其他平台适配器保留扩展边界。
技术实现Python、pandas、scikit-learn、Plotly 与 Streamlit。
使用提醒分析结果描述样本中的统计关联，不替代个人判断，也不构成因果结论。
