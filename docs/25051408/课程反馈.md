# 我的工作：

本次项目中我首先主导了立项，将选题确定为面向大学生求职的岗位数据分析与个性化推荐系统。原本我对金融数据分析更感兴趣，但考虑到组里对金融领域不熟悉就弃选了。

架构设计上，我先向AI提需求，再自己审查方案。因为做过类似的python项目，又主要是数据可视化，我选择了熟悉的streamlit。爬虫也没有从零设计，我直接到github找了适合的BOSS直聘采集工具，让AI接入项目。

开发时首要的问题是团队协作。我让组员准备好github账号和coding agent，从新建分支、commit、push到PR、Review，一点一点教他们。又写好AGENTS.md固定规范，厘清每个人的任务和验收标准。截至撰稿时，仓库共有256次commit，36个分支，合并53个PR，还是蛮有成就感的。

AI coding还是会出问题。起初我们没注意拉取最新main，就在各自分支一直写，结果企业和用户画像的字段不统一。我就在AGENTS.md里要求提交前先拉取改动、解决冲突。这些东西你不说，有时候AI真的会忘记。采集时它又只爬计算机岗位和上海、杭州，我只好停下来要求扩大职业领域和地域，把方向扭正。

前端同学做的页面太简陋，我看不下去，又帮他重新设计。我让AI先出几张图供我挑选，又加了frontend-design、taste-skill等skills。数据分析项目不用太花里胡哨，就定了这一张。

# 我的感受 ：

说实话，这门课算是很接近真实企业开发的了。总比之前整天念PPT的水课强。一个是老师间接倒逼我们真实的使用AI开发项目，逼我们学会使用git开发，这些是真正在工作会用到的，我深有所感。还有一个就是写日报这个确实有股“班味了”

AI Coding是未来的趋势，但这并不意味着我们就不用学了。相反，我们学的要比以前更多，既要懂以前传统的计算机基础。你要懂什么是CPU、GPU，懂缓存、内存、显存、磁盘，懂IP，DNS，http协议，不让就像本次项目实践，老师让发局域网网址，你发个localhost，那不是让人笑话吗？

还要懂怎么更好的使用AI。AI很强大，但你不会用就是废铁。我真实的感受就是，同一个模型，人家写的前端那么好看炫酷，我写的一股AI味儿。。。。。
