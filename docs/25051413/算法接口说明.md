## 2. 三类分析输出结构（已固定）

输出字段常量统一维护在 `src/data/schema.py`（纯新增，未改动既有字段）。

### 2.1 薪资因素分析 `analyze_salary_factors(jobs) -> pd.DataFrame`
列：`SALARY_FACTOR_COLUMNS = (factor, impact_direction, importance, description)`

| 列 | 含义 | 取值 |
|---|---|---|
| `factor` | 因子-取值，如 `学历-硕士`、`city-上海` | 字符串 |
| `impact_direction` | 相对整体均值的薪资方向 | `higher` / `lower` / `neutral` |
| `importance` | 该因子的归一化重要性 | 0~1，越高影响越大 |
| `description` | 可读说明（含组均值、样本数、整体均值） | 字符串 |

- 参与因子：学历、经验、城市、工作方式、公司性质、公司规模、行业（存在才分析，缺失自动跳过）；
- 输出为采集样本中的**统计关联**，不表述为因果关系。

### 2.2 岗位能力需求图谱 `build_skill_graph(jobs) -> dict`
键：`SKILL_GRAPH_KEYS = (nodes, edges, skill_frequency)`

| 键 | 结构 | 说明 |
|---|---|---|
| `nodes` | `[{id, label, count}]` | 技能节点及出现频次 |
| `edges` | `[{source, target, weight}]` | 同一岗位共同出现的技能对及次数 |
| `skill_frequency` | `[(skill, count), ...]` | 技能频率，按频次降序 |

### 2.3 招聘企业画像 `build_company_profiles(jobs) -> pd.DataFrame`
列：`COMPANY_PROFILE_COLUMNS = (company, company_size, company_nature, industry,
salary_summary, skill_summary)`

| 列 | 类型 | 说明 |
|---|---|---|
| `company` | string | 公司名（有效名才进入画像） |
| `company_size` | string | 公司规模（最常见值，缺失为空串） |
| `company_nature` | string | 公司性质（最常见值，缺失为空串） |
| `industry` | string | 行业（最常见值，缺失为空串） |
| `salary_summary` | dict | `{count, mean, min, max}`（薪资样本数、均值、上下限） |
| `skill_summary` | dict | `{技能: 出现次数}`（Top 5） |

## 3. 异常与空数据行为（统一约定）
| 场景 | 行为 |
|---|---|
| 空岗位表 | `ValueError("岗位数据为空，无法进行分析")` |
| 缺必填字段（`job_id/title/skills`） | `ValueError("岗位表缺少必填字段: ...")` |
| 缺 `salary_avg` | 因素分析 / 薪资预测抛明确错误 |
| 缺 `company` | 企业画像抛明确错误 |
| 样本不足（聚类 < 2×n_clusters；薪资 < 6） | 抛明确错误 |
| 薪资全缺失 | 因素分析 / 薪资预测抛明确错误 |
| 仅含冻结 `JOB_COLUMNS` | 三类分析仍可运行，可选因子自动降级 |
