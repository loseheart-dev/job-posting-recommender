# 岗位数据字典

## 1. 数据范围

- 数据来源：BOSS直聘
- 上游项目：`eatmoreduck/boss-zhipin-scraper` `v2.2.0`
- 固定 commit：`2bc40f56a3ca3249ce3b98cdda0187e0bd612aa5`
- 当前验证条件：关键词“大数据”、城市“上海”、1 页、最多 5 条详情
- 标准输出：`data/processed/jobs.csv`
- 清洗记录：`data/processed/cleaning_record.json`

## 2. 字段字典

| 字段 | 类型 | 单位/格式 | BOSS 来源 | 缺失规则 |
|---|---|---|---|---|
| `job_id` | string | 平台岗位 ID | `job_id`，缺失时回退 `encrypt_job_id`/`encryptJobId` | 缺失保留为空并记录，不能用标题代替 |
| `title` | string | 文本 | `title` | 缺失保留为空并记录 |
| `company` | string | 文本 | `boss_name`/公司名称 | 缺失保留为空并记录 |
| `company_intro` | string | 文本 | 当前上游列表/详情无稳定对应字段 | 留空，不推断 |
| `company_size` | string | 文本 | `company_scale` | 留空，不推断 |
| `company_nature` | string | 文本 | 当前上游无稳定对应字段 | 留空，不推断 |
| `industry` | string | 文本 | `company_industry` | 留空，不推断 |
| `city` | string | 城市名称 | `location` 的第一段 | 原文为空则留空 |
| `work_type` | string | 全职/实习/校招等 | `tags` 中的明确标签 | 没有明确标签则留空 |
| `experience` | string | 标准化文本 | `tags` 中的经验标签 | 没有标签则留空 |
| `education` | string | 标准化文本 | `tags` 中的学历标签 | 没有标签则留空 |
| `skills` | string | 英文分号分隔 | `skills` 或详情 `skill_tags` | 无技能或仅含明显岗位要求文本则留空 |
| `description` | string | 岗位描述文本 | 详情 `jd` | 详情失败或文本不足则留空 |
| `benefits` | string | 英文分号分隔 | `welfare` | 无福利则留空 |
| `salary_text` | string | 页面原文 | `salary` | 原文缺失则留空 |
| `salary_min` | float | 人民币元/月 | 由 `salary_text` 解析 | 无法解析则留空 |
| `salary_max` | float | 人民币元/月 | 由 `salary_text` 解析 | 无法解析则留空 |
| `salary_avg` | float | 人民币元/月 | `(salary_min + salary_max) / 2` | 任一边界缺失则留空 |
| `source` | string | 固定值 | 适配器写入 `BOSS直聘` | 不允许为空 |
| `source_url` | string | URL | `job_link` | 缺失保留为空 |
| `crawled_at` | string | ISO 8601 | 采集/导入时间 | 不允许为空 |

## 3. 统一规则

1. 输出始终按《接口约定》和 `src.data.schema.JOB_COLUMNS` 的顺序排列。
2. 文本字段去除首尾空白；技能和福利中的 `|`、逗号、分号统一为英文分号，并去除重复值。
3. 城市取 `location` 的第一段，并去除末尾“市”；不能识别的非空城市保留原文本。
4. `K`/`k`/`千`按 1000 元/月换算；`万`按 10000 元/月换算；`元/天`按 21.75 个工作日折算为元/月。
5. “面议”等无法解析的薪资不填 0；算法统计时只使用有效薪资样本。
6. 只按非空 `job_id` 去重并保留首次记录；缺失 ID 的记录不互相覆盖。
7. 原始输入不覆盖，清洗输出和清洗记录分别保存；所有路径、记录数、重复数和缺失值统计写入清洗记录。
8. 时薪按 8 小时/天、21.75 个工作日/月折算，周薪按 52/12 周/月折算；无法确认单位时不擅自换算。
