# 服务层调用说明（徐挚凌 25051430）

> 供页面集中联调使用。约定：页面统一通过 `src/services` 的函数读取、筛选、统计与调用算法，**不直接读取原始数据，也不直接 import `src.algorithms`**（模型逻辑由 `analysis_service` 统一封装）。

## 1. 数据入口与基础统计

| 函数 | 作用 | 空数据契约 |
|---|---|---|
| `src.data.loader.load_jobs(path)` | 读取标准 21 列岗位表；缺文件返回空表（带标准列），空文件/缺必填字段抛明确错误 | 返回空表不抛错（缺文件时） |
| `job_service.filter_jobs(jobs, filters)` | 9 键筛选（keyword/city/work_type/experience/education/industry/company_nature/salary_min/salary_max），返回标准列、不改输入 | 无结果返回空表，不抛错；未知键抛 ValueError |
| `job_service.summarize_jobs(jobs)` | `job_count / salary_count / salary_min / salary_max / salary_avg / top_skills` | 空表返回全空统计（count=0、avg=None） |
| `job_service.salary_distribution(jobs, step=5000.0)` | 基于 salary_avg 分桶，返回 `[{range,min,max,count}]` | 空数据返回 `[]`；step<=0 抛 ValueError |

## 2. 分析与推荐（`src.services.analysis_service`）

- `salary_factor_analysis(jobs)`：薪资因素（`factor/impact_direction/importance/description`）
- `salary_prediction(jobs)`：返回 `(带 predicted_salary 的岗位表, {mae,r2})`
- `job_cluster(jobs, n_clusters=3)`：返回 `(带 cluster_id 的岗位表, 群组说明)`
- `skill_graph(jobs)`：返回 `{nodes, edges, skill_frequency}`
- `company_profile(jobs)`：企业画像（`company/.../salary_summary/skill_summary`）
- `recommend_jobs(profile, jobs, top_k=5)` / `recommend_jobs_multifactor(profile, jobs, top_k=5)`：画像传 dict 或 `StudentProfile`

**空数据契约**：分析类函数空表抛中文 `ValueError`；推荐类函数遵循丁伟哲冻结契约——空表/空画像返回空结果表（不抛错），页面按"无推荐结果"处理。

## 3. 网站配置与采集任务（`site_service` / `task_service`）

- `site_service`：`add_site / list_sites / get_site / update_site / set_site_enabled / remove_site / ensure_default_site`
- `task_service`：`trigger_task / update_task / list_tasks / get_task / compute_next_run`

## 4. 页面最小调用示例

```python
from src.data.loader import load_jobs
from src.services.job_service import filter_jobs, salary_distribution, summarize_jobs
from src.services import analysis_service as ana

jobs = load_jobs("data/processed/jobs.csv")   # 缺真实数据时用 "tests/fixtures/expanded_jobs.csv"
filtered = filter_jobs(jobs, {"city": "上海", "education": "本科"})
summary = summarize_jobs(jobs)                 # 总览统计
dist = salary_distribution(jobs)               # 薪资分布（绘图）
factors = ana.salary_factor_analysis(filtered) if not filtered.empty else None
graph = ana.skill_graph(jobs)
recs = ana.recommend_jobs_multifactor(
    {"target_role": "数据分析", "skills": "Python;SQL", "preferred_city": "上海"}, jobs, top_k=5)
```
