# 调研报告

## 一、同类产品调研

| 调研对象 | 主要功能 | 数据与技术特点 | 对本项目的参考价值 |
|---|---|---|---|
| [BOSS直聘](https://www.zhipin.com/) | 职位搜索、企业查看、校招和沟通 | 按职位、城市、行业等条件组织岗位，推荐规则未公开 | 作为首期数据来源，重点分析岗位、薪资和企业信息 |
| [智联招聘](https://www.zhaopin.com/) | 校招、实习、职位搜索和投递 | 岗位通常包含职位、地区、学历、经验和企业信息 | 作为后续平台扩展和岗位差异比较对象 |
| [前程无忧](https://www.51job.com/) | 全职、实习、校招、职位搜索和投递 | 覆盖职位、薪资、地区、经验和企业等信息 | 作为后续平台扩展和数据对比对象 |

三个平台都能帮助用户搜索岗位，但平台内部推荐算法通常不公开，用户难以了解排序依据。本项目不复制聊天和投递功能，而是采集限定范围的公开岗位信息，统一字段后分析薪资、技能和企业特征。

## 二、技术项目调研

1. [boss-zhipin-scraper](https://github.com/eatmoreduck/boss-zhipin-scraper)：通过 Chrome DevTools Protocol 读取页面自身返回的岗位列表数据，并输出 JSON/CSV。本项目固定其版本，在独立浏览器用户目录中手动登录，再自行完成任务遍历、字段映射和清洗。
2. [scikit-learn 文本特征提取](https://scikit-learn.org/stable/modules/feature_extraction.html)：提供 TF-IDF 等文本表示方法，用于岗位与求职者画像的基础匹配。
3. [scikit-learn 聚类和集成学习](https://scikit-learn.org/stable/modules/clustering.html)：KMeans 可用于岗位分组，随机森林可用于薪资预测，适合课程原型阶段的可解释实现。

## 三、对比与结论

BOSS 直聘适合作为首期数据入口，因为上游项目已经提供了可复现的浏览器数据读取方式；智联招聘和 51job 作为后续扩展，不在平台规则和数据质量未确认时提前接入。技术上采用“上游采集适配器 + 自研 BFS/DFS + 统一清洗 + 可解释算法”的路线，既复用了成熟工具，也保留了本项目自己的遍历和分析部分。

项目数据只处理岗位信息，不采集手机号、简历、Cookie 等敏感信息。采集受登录、验证码和平台访问规则影响时保留真实记录，不绕过限制。
