# 面向大学生求职的岗位数据分析与个性化推荐系统

本项目面向实习和校招大学生，首期采集 BOSS 直聘的大数据相关岗位，解决岗位信息分散、待遇难比较和求职方向难判断的问题。系统完成岗位采集、字段解析、数据清洗、薪资分析、能力需求分析、企业画像和个性化推荐。

## 功能与技术

- 通过独立 Chrome 用户目录和手动登录获取 BOSS 岗位数据，支持按关键词、城市和任务进行 BFS/DFS 遍历；
- 统一职位、薪资、地区、学历、经验、技能和企业字段，保留原始结果、缺失标记和清洗记录；
- 使用 Python、pandas、PySpark/Spark、scikit-learn 和 Streamlit，采用 TF-IDF、KMeans、随机森林等方法；
- 根据学历、专业、学校、求职地、工作年限、技能、工作经历和目标岗位输出待遇区间、适配企业、匹配概率和推荐理由；
- 支持网站配置、采集任务调度、岗位筛选和结果展示。首期采用按需或定时批量采集，不承诺持续实时更新。
