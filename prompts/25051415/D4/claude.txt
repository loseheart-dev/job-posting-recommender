  ▎ PR；仅拆成多个 commit 仍可能造成 PR diff 过大。

  条款含义

  - 拆分对象：大体积测试数据（典型即 tests/fixtures/expanded_jobs.csv）和课程过程记录（daily/ 日报、prompts/
    提示词导出）这类文件;
  - 拆分方式：必须放到与功能代码不同的分支、不同的 PR 中提交;
  - 约束点：单纯在同一分支内拆成多个 commit 不算拆分——因为 PR 的 diff 是合并后相对 base 的全部变更,大文件只要进了同一
    PR,无论拆多少 commit,diff 体积依然过大;
  - 目的：控制 PR diff 规模,避免 8000+ 行的真实采集数据（expanded_jobs.csv）或大段提示词文本淹没代码评审。
