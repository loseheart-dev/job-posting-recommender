# Job Posting Recommender

面向大学生求职的岗位数据分析与个性化推荐系统。

项目以在线招聘平台岗位数据采集为数据入口，先采集原始岗位信息，再完成清洗、分析、预测、推荐和可视化。首期以智联招聘和前程无忧（51job）为目标平台，限定明确的岗位范围跑通采集闭环，后续再扩展数据来源。

## 必须实现的功能

- 采集智联招聘、前程无忧（51job）等平台的大数据相关岗位信息，至少提取职位名称、职位待遇、职位描述、公司介绍、公司规模、公司性质、行业、学历、经验、技能等字段；
- 支持网站列表管理、采集任务开始时间和采集频率配置，并为新增网站保留水平扩展边界；
- 提供深度优先和广度优先两种网页遍历策略，保留项目自研的遍历算法；
- 完成薪资影响因素、岗位能力需求图谱和招聘企业画像三类分析；
- 根据求职者学历、专业、学校、求职地、工作年限、技能、工作经历和岗位名称，输出待遇水平、个人待遇区间、适配企业、企业性质与规模、行业和匹配概率；
- 完成岗位数据获取与预处理、数据可视化分析、多元职位推荐模型、职位信息展示和个性化推荐系统。

创新功能在上述内容完成后再安排，不作为基础功能的替代。

技术路径为“在线岗位采集 → 原始数据保存 → PySpark/Spark 大数据处理与分析 → 推荐服务 → Streamlit 展示”。pandas 用于字段清洗和小样本处理，PySpark 负责可扩展的数据统计与挖掘。

## 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

岗位采集结果先保存到 `data/raw/`，经清洗后输出到 `data/processed/jobs.csv`。没有清洗后数据时，页面会显示数据准备提示。采集过程需要记录平台、采集范围、时间和数据来源，不采集个人联系方式、账号信息等敏感内容。

## 共享接口

岗位表、学生画像、筛选参数和算法返回字段已经固定，详见 [接口约定.md](docs/接口约定.md)。代码中的字段常量和数据类位于 `src/data/schema.py`，组员不需要互相等待确认列名。卢世豪负责采集、清洗契约和字段变更审核，郑维豪负责算法输出字段，变更前先说明原因。

联调按“采集基线 → 清洗基线 → 分析与推荐基线 → 服务基线 → 页面联调”进行。每个人先在自己的分支完成正常和异常案例，卢世豪审核后再合并到 `main`，未通过上一阶段不进入下一阶段。

## 目录说明

```text
app.py                    Streamlit 启动入口
src/data/                 网站采集、数据读取和清洗
src/algorithms/           因素分析、聚类、预测、图谱和个性化推荐
src/services/             采集管理、筛选、统计和模块联调
src/ui/                   采集管理、分析看板和推荐展示
data/raw/                 在线采集的原始岗位数据，不提交真实敏感数据
data/processed/           清洗后数据
```
